🛕 Somnath Temple: Digital Sanctum

An immersive, high-fidelity web experience dedicated to the architectural and spiritual grandeur of the Somnath Temple. This project leverages modern web technologies to create a seamless, cinematic journey through one of India's most sacred landmarks.

✨ Key Features
🎬 Cinematic Animations: Smooth, scroll-triggered storytelling powered by GSAP and ScrollTrigger.
🌊 Fluid Motion: Integration of Lenis Smooth Scroll for a premium, non-jittery user experience.
🏗️ 3D Visualization: Interactive elements brought to life using Three.js.
📱 Responsive Excellence: A "Mobile-First" architecture ensuring a perfect look on all devices via Tailwind CSS v4.
⚡ Ultra-Fast Performance: Optimized assets and code-splitting through the Vite build tool.
🛠️ Tech Stack
Core: HTML5, CSS3, JavaScript (ES6+)
Styling: Tailwind CSS v4 (Modern Utility-First Engine)
Animation: GSAP (GreenSock Animation Platform)
Smooth Scrolling: Lenis
3D Graphics: Three.js
Build Tool: Vite
🚀 Getting Started
Follow these steps to set up the project locally:

1. Clone the Repository
bash
git clone [https://github.com/your-username/somnath-temple-digital.git](https://github.com/Aayush8113/somnath-temple)
2. Navigate to Project Directory
bash
cd somnath-temple-digital
3. Install Dependencies
bash
npm install
4. Start Development Server
bash
npm run dev
The application will be available at http://localhost:5173.
